# Samuel Salin — Games and Unreal Prototypes

Gameplay, multiplayer, Unreal C++/Blueprints and interactive systems.

[Portfolio](https://samuelsalin.com) · [LinkedIn](https://www.linkedin.com/in/samuel-salin/)

This is a documentation and gameplay showcase. It does **not** distribute source code, engine assets or employer-owned work. Project status is stated explicitly; prototypes are not presented as shipped games.

| Project | Current evidence and limits |
|---|---|
| [Momo’s Adventures](projects/momos-adventures/README.md) | UE 5.8.3 build and automated traversal/regression checks passed. Animation polish and human playtest feedback remain. |
| [MoodCrowd](projects/moodcrowd/README.md) | Existing project targets UE 5.7. Mannequin behavior tests passed; rendered material/readability issues remain. |
| [Roblox prototypes](projects/roblox-prototypes/README.md) | Source/logic and packaging checks exist. Studio, live persistence, device usability and real multiplayer validation are incomplete. |
| [Unreal Voice Studio](projects/unreal-voice-studio/README.md) | UE 5.8.3 build and live typed turn validated. One warmed turn: 3.14 seconds to audio. No p95/microphone guarantee; renderer flicker unresolved. |
| [NetWitness](projects/netwitness/README.md) | Prototype with limited late-join/overflow evidence; synchronous writes and ordinary replicated arrays require overhead evaluation. |
| [ForgeKit](projects/forgekit/README.md) | Descriptor targets UE 5.7. Current functionality and validation need audit before public capability claims. |
| [GAS prediction lab](projects/gas-prediction-lab/README.md) | 36 restarted server/owner pilot sessions recorded. Candidate finite-state protocol is not an implemented engine solution or a breakthrough. |
